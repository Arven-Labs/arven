# arven

Site mãe da Arven Labs e seu backend: conta, planos, cobrança e entitlements dos produtos da organização. Cada produto mantém o próprio backend e fala com este apenas por API; os sites dos produtos são só vitrine, instalação e documentação.

**Status:** pré-projeto. Só o [documento de design](project/SPEC.md) existe; stack, gateway de pagamento e domínio estão em aberto. Estado em [`project/OVERVIEW.md`](project/OVERVIEW.md).

## Documentação

- [`project/INDEX.md`](project/INDEX.md): ponto de entrada.
- [`project/SPEC.md`](project/SPEC.md): design da plataforma (arquitetura, responsabilidades, cobrança, autenticação, entitlements).
- [`project/adr/`](project/adr/): registros de decisão de arquitetura.
