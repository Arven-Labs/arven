# 0001: Nome do projeto: arven

**Data:** 2026-11-12

## Contexto
O documento de design chamava o projeto só de "plataforma da organização". É o repo do site mãe e do backend de conta, planos, cobrança e entitlements.

## Decisão
O projeto se chama **arven** (`Arven-Labs/arven`), o mesmo nome da marca.

## Alternativas
- `arven-platform` ou `site`: mais explícitos, porém redundantes dentro da organização.

## Consequências
- O repo `arven` é "o site da Arven"; fácil de achar.
- Risco: o nome do repo coincide com o da marca e pode virar ambíguo se houver outro repo da marca. Renomear depois é possível (o GitHub redireciona).
